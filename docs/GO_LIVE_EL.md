# Οδηγός για production (τι μένει από εσάς)

Όλα τα βήματα με τη σειρά. Κανένας κωδικός δεν υπάρχει σε αυτό το αρχείο ή στο repo: οι τιμές
μπαίνουν μόνο στο Netlify.

## 1. Μεταβλητές στο Netlify (Site configuration → Environment variables)

### Admin panel

| Μεταβλητή                  | Τιμή                                                                               |
| -------------------------- | ---------------------------------------------------------------------------------- |
| `ADMIN_BOOTSTRAP_EMAIL`    | `devtaskhub@gmail.com`                                                             |
| `ADMIN_BOOTSTRAP_PASSWORD` | ο κωδικός που επιλέξατε για τον admin                                              |
| `PLATFORM_ADMIN_EMAILS`    | `devtaskhub@gmail.com` (ή διαγράψτε τη, αν έχει ακόμα άλλο email, π.χ. το xsiwzos) |

Στο επόμενο deploy το build δημιουργεί τον λογαριασμό admin (με επιβεβαιωμένο email) ή, αν
υπάρχει ήδη, του δίνει δικαιώματα admin και βάζει αυτόν τον κωδικό. Στο log του build θα δείτε
μόνο `admin bootstrap: created devtaskhub@gmail.com` (ποτέ τον κωδικό).

Μετά την πρώτη σύνδεση:

1. Συνδεθείτε στο `https://www.hournook.com/login` με `devtaskhub@gmail.com`: ανοίγει κατευθείαν το
   `/admin`.
2. Αλλάξτε τον κωδικό στο `/admin/account`.
3. **Διαγράψτε** τις `ADMIN_BOOTSTRAP_PASSWORD` και `ADMIN_BOOTSTRAP_EMAIL` από το Netlify (αλλιώς
   κάθε deploy ξαναβάζει τον αρχικό κωδικό).

Ο λογαριασμός της επιχείρησής σας (xsiwzos@gmail.com) μένει κανονικός λογαριασμός επιχείρησης.
Αν στο `/admin/users` εμφανίζεται κι αυτός ως admin (από παλιότερη ρύθμιση), πατήστε εκεί
«Revoke admin».

### Stripe (μόνο όταν περάσετε σε live, βλ. βήμα 4)

Βάλτε τις live τιμές **μόνο στο context "Production"** (όχι "All"), ώστε τα previews να μη
χρεώνουν ποτέ πραγματικές κάρτες.

| Μεταβλητή                | Τιμή                                                                  |
| ------------------------ | --------------------------------------------------------------------- |
| `STRIPE_SECRET_KEY`      | `sk_live_…`                                                           |
| `STRIPE_LIVE_MODE`       | `enabled` (χωρίς αυτή, τα live κλειδιά απορρίπτονται)                 |
| `STRIPE_WEBHOOK_SECRET`  | **διαγράψτε το** τεστ `whsec_…` (το live webhook φτιάχνεται αυτόματα) |
| `STRIPE_PUBLISHABLE_KEY` | προαιρετικό· αν υπάρχει, πρέπει να είναι `pk_live_…`                  |
| `STRIPE_PRICE_ID`        | κενό (η τιμή €10/μήνα με ΦΠΑ φτιάχνεται αυτόματα)                     |
| `STRIPE_AUTOMATIC_TAX`   | κενό (τον ΦΠΑ τον βγάζει το Workadu, βλ. παρακάτω)                    |
| `APP_SECRET`             | μην το αλλάξετε ποτέ (κρυπτογραφεί το webhook secret)                 |

## 2. Δοκιμή στο πραγματικό site, ακόμα σε test mode

Ό,τι δεν μπορεί να ανοίξει μέσα στο sandbox μου (οι σελίδες του Stripe και η πραγματική
αποστολή email) το ελέγχετε εσείς σε 5 λεπτά, με τα **test** κλειδιά που ήδη έχετε:

1. Κάντε εγγραφή με ένα νέο email: το email επιβεβαίωσης πρέπει να φτάσει σε λίγα δευτερόλεπτα.
2. Ανοίξτε Χρεώσεις → «Συνδρομή με …» → κάρτα `4242 4242 4242 4242`, οποιαδήποτε μελλοντική
   ημερομηνία, οποιοδήποτε CVC.
3. Επιστρέφετε στις Χρεώσεις και σε λίγα δευτερόλεπτα βλέπετε «Η συνδρομή σας είναι ενεργή» με
   «VISA •••• 4242». Αν ο λογαριασμός είναι ακόμα στη δωρεάν δοκιμή, οι μέρες που απομένουν
   μεταφέρονται: βλέπετε «Συνδρομητής» και η πρώτη χρέωση €10 γίνεται όταν λήξει η δοκιμή. Αυτό
   είναι το σωστό, ώστε κανείς να μην πληρώνει μέρες που του χαρίστηκαν.
4. «Διαχείριση χρέωσης» → Cancel: βλέπετε «Η συνδρομή σας λήγει: …» και η σελίδα κρατήσεων
   δουλεύει μέχρι τότε.
5. Stripe (test) → Developers → Webhooks: όλες οι αποστολές με **200**.

## 3. Ρυθμίσεις στο Stripe Dashboard (live mode)

1. **Business details**: επωνυμία, email/τηλέφωνο υποστήριξης, website
   `https://www.hournook.com`, privacy `https://www.hournook.com/privacy`, terms
   `https://www.hournook.com/terms`, λογότυπο.
2. **Statement descriptor**: π.χ. `HOURNOOK`.
3. **Receipts**: Settings → Billing → Customer emails → ενεργοποιήστε τα emails για επιτυχημένες
   πληρωμές (τα τιμολόγια τα στέλνει το Workadu, ώστε να μη λαμβάνει ο πελάτης δύο έγγραφα).
4. **Failed payments**: Smart Retries για 2 εβδομάδες και μετά **cancel the subscription**. Η
   εφαρμογή σταματά τις κρατήσεις 7 ημέρες μετά την πρώτη αποτυχία και τις ξανανοίγει μόλις
   πληρωθεί.
5. **Customer portal**: cancel **at end of billing period** (με λόγους ακύρωσης), αλλαγή κάρτας,
   ιστορικό τιμολογίων.
6. **ΦΠΑ**: αφήστε το `STRIPE_AUTOMATIC_TAX` κενό. Ο πελάτης χρεώνεται πάντα €10,00 και το Workadu
   εκδίδει το παραστατικό (€8,06 + ΦΠΑ 24% €1,94) προς myAADE.
7. **Workadu**: συνδέστε τον **live** λογαριασμό Stripe και ελέγξτε ότι το live webhook του είναι
   ενεργό. Για επιστροφές χρημάτων χρειάζεται πιστωτικό (ελέγξτε αν το κάνει αυτόματα).
8. Στο **test** mode διαγράψτε τα παλιά webhook endpoints των `*.netlify.app`.

## 4. Μετάβαση σε live

1. Στη βάση (Neon → SQL Editor), **ακριβώς πριν** το live deploy: `DELETE FROM subscriptions;`
   (όλες οι συνδρομές ως τώρα είναι δοκιμαστικές).
2. Αλλάξτε τις μεταβλητές Stripe στο Netlify (πίνακας πάνω) και κάντε deploy.
3. Στο log του build πρέπει να δείτε `[stripe:setup] Stripe live mode`, `plan price: price_…`,
   `portal configuration: bpc_…` και `webhook created: we_… → https://www.hournook.com/api/stripe/webhook`.

## 5. Πρώτη πραγματική αγορά €10 και επιστροφή

1. Στη δική σας επιχείρηση τελειώστε τη δοκιμή:
   `UPDATE businesses SET trial_ends_at = now() WHERE slug = '<το-link-σας>';`
2. Χρεώσεις → «Συνδρομή με …» → πραγματική κάρτα (θα ζητηθεί 3-D Secure).
3. Ελέγξτε: Stripe → Payments €10,00 succeeded· Webhooks όλα 200· η εφαρμογή δείχνει ενεργή
   συνδρομή· το Workadu έβγαλε παραστατικό στο myAADE.
4. Επιστροφή: Stripe → Payments → Refund (€10,00) **και** Cancel the subscription → Immediately.
5. Βάλτε ξανά την επιχείρησή σας σε ενεργό πλάνο (νέα συνδρομή ή παράταση δοκιμής από το admin
   panel).

## 6. Νομικά και μεταφράσεις

- Τα αγγλικά νομικά κείμενα είναι αυτά που ενέκρινε ο δικηγόρος σας, χωρίς καμία αλλαγή.
- Οι μεταφράσεις σε άλλες 14 γλώσσες δείχνουν στην κορυφή σημείωση ότι σε περίπτωση διαφοράς
  ισχύει το αγγλικό κείμενο, με link σε αυτό.
- Προτείνεται ο δικηγόρος να ρίξει μια ματιά στην **ελληνική** μετάφραση (`/el/terms`,
  `/el/privacy`, `/el/dpa`), αφού οι περισσότεροι πελάτες σας είναι Έλληνες.

## 7. Google Search Console

Υποβάλετε ξανά το `https://www.hournook.com/sitemap.xml`. Τώρα περιέχει κάθε σελίδα σε 15
γλώσσες με hreflang, και τις σελίδες κρατήσεων στη νέα μορφή `www.hournook.com/<όνομα>`.

## Links κρατήσεων

Οι σελίδες κρατήσεων είναι πλέον `www.hournook.com/<όνομα>`. Όλα τα παλιά links
`www.hournook.com/book/<όνομα>` (και τα τυπωμένα QR) ανακατευθύνονται μόνιμα στο νέο link,
κρατώντας τις παραμέτρους (π.χ. `?src=qr`, `?lang=el`). Δεν χρειάζεται να ξανατυπώσετε τίποτα.
